# Ultra Capsule Adventure (모드ID `UltraCapsuleAdventure`) — MC 26.3 Fabric

마인크래프트 자바 **26.3 Wilderness Bound** 대응 Fabric 모드.
캡슐 7종(파트너/소울/도박/분해/공허/메카/타이탄) + 불길의 검 + 메두사/석화 + 규산 장비/운석 + 먹보 도깨비/공허 액체 + 도플갱어(밤의 스토커).

- Fabric Loader `0.19.5`, Fabric API `0.161.0+26.3`, Loom `1.18-SNAPSHOT`, Java `25`
- 위치: `E:\user\개인 작업\마크 모드 제작소\ultra capsule adventure final`

## 캡슐 일람

| 캡슐 | 조합법 | 용도 한 줄 |
|---|---|---|
| 울트라 캡슐 어드벤처 | `철괴 4 + 엔더진주 1` (` I /IEI/ I `) | 길들인 몹 보관/소환/관리 |
| 소울 캡슐 | `유리 4 + 소울샌드 1` (` G /GSG/ G `) | 불길의 검 처치 영혼 저장 → 아군 소울 소환 (최대 Lv.3 합성) |
| 도박 캡슐 | `유리 5 + 레드스톤 4` (`GRG/RGR/GRG`) | 아이템 장전 → 10초 후 확률로 배율 지급/소멸 (행운·약탈 인챈트 연동) |
| 분해 캡슐 | `철괴 4 + 화로 1` (`I I/ F /I I`) | 아이템 역조합 분해 (닳은 도구 불가) |
| 공허 캡슐 | `철괴 4 + 공허 양동이 1` (` I /IBI/ I `) | 엔티티 흡수 → 풀어주기/존재 삭제(2시간 되돌림) |
| 타이탄 캡슐 | `철블록 2 + 다이아 2 + 자수정 조각 1` (` I /DAD/ I `) | 장비 점진 수리 + 손상된 모루 복원 + 메두사 머리 충전 |
| 메카 캡슐 | 조합 불가. 도구제작자 마스터 거래 `에메랄드 10 → 메카 캡슐` (재고 1) | 3초 충전 → 탑승형 로봇 변신 |
| 은신 캡슐 | `철괴 4 + 파란 점토 1` (` I /IBI/ I `) | 황혼의 검 처치 엔티티 무제한 등록 → 변신 (C키 관리창) |
| 불길의 검 | `화염룡의 피 2 + 막대 1` (수직 `D/D/S`) | 네더라이트급 검. 처치 시 소울 자동 흡수. 수리=`블레이즈 막대` |
| 황혼의 검 | `파란 점토 2 + 막대 1` (수직 `B/B/S`) | 맞은 적 어둠+감속. 처치 시 은신 캡슐에 등록 |

## 조작키 / 관리창

- `C`: 손에 든 캡슐 탭으로 관리창 열기. 상단 버튼으로 탭 순환: 파트너 → 영혼 → 공허 → 타이탄 → 도박 → 분해 → 메카 → 은신
- `H`: 몸속 소울 꺼내기/집어넣기 (밖에 있으면 회수, 없으면 몸속→캡슐 순 소환)
- 메카 탑승 중: `WASD` 이동 + 스프린트 가속, `좌클릭` 레이저, `스페이스` 점프, `Shift` 하차
- 크리에이티브 탭 `UltraCapsuleAdventure:main`에 캡슐/검/양동이/스폰알/머리/규산 세트 전부 포함

## 주요 사용법

### 울트라 캡슐 어드벤처
- 길들인 몹 우클릭 → 반경 64m 내 내 길들임 전부 저장(`saveAsPassenger` + 체력/이름/안장/갑옷 캐시). 허공/블록 우클릭 → 소환(5열 그리드).
- 관리창: 체력바·이름 변경·회복(클릭 1회분/0.6초 꾹 풀회복, 음식 소모)·안장/갑옷 장착·개별 소환·상세 미리보기·불러내기(512m 순간이동+앉기 해제).

### 소울 캡슐 + 불길의 검
- 불길의 검(주손/보조손)으로 처치 → 빈 소울 캡슐(손→인벤토리 순 탐색)에 자동 흡수. 아군 소울 킬은 무기 무관 흡수. 소울 캡슐 약탈 인챈트 Lv당 1기씩 추가 흡수 (기본 1기, 최대 4기).
- 지정 인챈트는 약탈만. 인챈트 테이블에는 약탈만 뜨고, 모루·책으로 붙인 지정 외 인챈트는 5초 검사에서 제거됨.
- 같은 종류·같은 레벨 2마리 합성 → Lv+1 (최대 Lv.3, Lv.2=1.5배, Lv.3=2.0배 체력/공격).
- 우클릭 소환, 웅크리기 우클릭/내 소울 우클릭/`H`로 회수. 사망 시 자동 회수 + 리스폰 후 자동 소환(`autoOut`). 내 소울끼리 오폭 없음(같은 주인 피해 무효+스플래시 차단), 파란 팀 발광.
- GUI: 개별 소환/합성/삭제, 모두 소환/불러내기(타 차원도 추적 재소환).

### 도박 캡슐
- 우클릭 또는 `C`창에서 아이템 장전(캡슐류 제외, 스택 통째) → 시작 → 10초(`until`) 후 해소. 기본 승률 50%·2배 분할 지급, 패: 소멸. 시작 후 취소 불가. 인챈트 연동: 행운 Lv당 성공률 +10%(최대 80%), 약탈 Lv당 배율 +1(최대 5배).
- 지정 인챈트는 행운·약탈만. 인챈트 테이블에는 둘만 뜨고, 지정 외(날카로움·밀치기·실크터치 등)는 5초 검사에서 제거됨.

### 분해 캡슐
- 아이템 장전 → 예상 재료 표시(`Shaped/Shapeless` 첫 매칭) → 분해 실행 시 1개 소모하고 재료 각 1개 반환. 닳은 도구/조합법 없음 불가.

### 공허 캡슐
- 들고 `LivingEntity`(플레이어/석상/석화 제외) 우클릭 흡수(장비 포함 저장). `use()` 단독 기능 없음, 전부 `C`창 조작.
- 풀어주기: 플레이어 앞 1m 소환. 존재 삭제: 2시간(`REWIND_WINDOW 7200000ms`) 로그 기준 되돌림 — 피해자 체력 회복+해로운 효과 제거, 자식 연쇄 삭제, 킬 피해자 부활+드롭/경험치 제거+검은 액체 제거, 석화 해제, 휴대 장비 반환, 주민 거래差 역적용, 좀비화 48m 내 치료.

### 타이탄 캡슐
- 빈손 우클릭=반대손 아이템 맡기기, 모루 우클릭=모루 복원 예약. `C`창에서도 맡기기/꺼내기/중단. 수리 가능: 닳은 장비/도구, 닳은 메카 캡슐, 미충전 메두사 머리 (다른 캡슐은 불가).
- 수리 시간: 메두사 머리 고정 75초, 모루 90초, 일반 장비 `secs=(base+ench)×(0.35+0.65×손상률)`, `base=clamp(최대내구/16, 6, 150)`, `ench=8×min(10, 인챈트 수)`, 5~240초. 매틱 내구도 점진 회복, 완료 시 자동 반환 + 3분 쿨타임. 중단 시 진행도 유지·쿨 없음. 타이탄 캡슐 인챈트 연동: 효율 Lv당 수리 시간 -10%(최대 -50%), 빠른 장전 Lv당 쿨타임 -15%(최대 -45%).
- 지정 인챈트는 효율·빠른 장전만. 인챈트 테이블에는 둘만 뜨고, 지정 외(다중 발사·관통 등)는 5초 검사에서 제거됨.

### 메카 캡슐
- 들고 우클릭 3초(60틱) 충전(이펙트+음 상승) → 캡슐 투척 → 착지 지점에서 변신(포드 진동→섬광→부품 전개, 70틱, 변신 중 무적).
- 우클릭 탑승(주인만, 탑승자는 몸·갑옷·손 통째로 숨김). 카메라가 메카 얼굴 높이(바이저)에 와서 메카가 된 것처럼 조종. `WASD+스프린트`, 좌클릭 레이저(150뎀·64m·쿨 25틱, 얼굴에서 발사), 스페이스 점프. 체력 200, 낙뎀 없음, 넉백 면역.
- 서바이벌·어드벤처에서 탑승 중이면 플레이어 무적 + 몹 어그로가 메카로 전환 (하차하면 보호 해제, 크리에·관전 제외).
- 1인칭 탑승 시 메카 몸 안 조종석 시점: 탑승자 눈 위치 기준 닫힌 캐빈(바닥·계기판·천장·기둥·측벽·후벽·좌석·조종간) 안에 들어가고, 앞쪽 열린 창으로 밖을 봄 (겉모습은 숨김, 시선 pitch의 80%만 따라 기울어 몸에 달린 느낌). 조종석은 탑승자 본인의 1인칭에서만 그려지고 3인칭·다른 플레이어·밖에서는 보이지 않음 (석상은 정상).
- `Shift` 하차 → 웅크리기 우클릭 40틱 유지 → 접힘 후 캡슐이 날아와 인벤토리로 귀환. 탑승 중 좌클릭 3초(60틱) 꾹 유지해도 즉시 하차 후 접힘 시작 (변신 충전과 동일한 게이지+음 상승, 떼면 취소).
- 로봇 체력 ↔ 캡슐 내구도 1:1 연동 (복귀 시 체력만큼 내구도 기록, 변신 시 내구도만큼 체력). 탑승 HUD 차량 체력 하트가 실제 로봇 HP와 동기화. 파괴 시 닳은 캡슐 드롭(타이탄 수리 가능). 닳은 메카 캡슐은 타이탄 캡슐로 수리 가능 (수리하면 다음 변신 풀체력). 석상 상태에선 탑승·발사·점프 불가. 로봇이 석화되면 탑승자는 즉시 강제 하차.

### 메두사 / 석화 / 메두사의 머리
- 스폰: 비 올 때, 서바이벌 플레이어 기준 30초마다 40% 판정, 24~40m, 64m 내 2마리 상한. HP60/공6/추적 28m. 근접 독 3초. 사망 시 머리 100% 드롭.
- 석화: 16m 이내 상호 응시(31° 이내·시야 확보) 0.25초 유지 → 발동(눈 섬광+사운드). 원본 그 자리 동결(자세 그대로, 무적·무AI·무중력·고정·타겟 제외). 플레이어는 마네킨 석상+본인 사망.
- 안대: 조합 `실+가죽+실` 1줄. 투구 슬롯 장착 시 눈에 맞는 밴드 렌더 + 실명 효과 유지(앞이 안 보임) 대신 메두사 시선 석화(본체 응시·머리 발사 모두) 면역.
- 채굴: 돌 캘 수 있는 곡괭이로만 파괴 → 조약돌 2개. 그 외 공격/사망 무효. 가해 메두사 삭제 시 그 애가 돌린 석화 해제.
- 머리: 잔여 횟수는 내구도 게이지로 표시 (5회분, 다 써도 미세하게 남아 사라지지 않음). 조준(32m) 후 놓으면 1회 원거리 석화 → 재충전 필요(타이탄 캡슐 75초). 크리에이티브 무한.

### 도플갱어 (밤의 스토커)
- 출현 조건: 월드 20일 이상 + 밤(13000~23000)에만 플레이어 근처(14~22m) 스폰. 낮에는 데미지 없이 새벽에 소멸(스토킹 일수 +1).
- 행동: 스토크 단계(10~20m 유지, 눈 마주치면 나무 뒤로 순간이동, 가끔 바닐라 몹으로 변장) → 며칠 후 매복 돌변(정면 3m 소환·근접 공격).
- 처치 시 파란 점토 3개. 낮 화상 데미지 없음(새벽 소멸이 수명 관리).
- 캡슐 호환: 불길의 검 처치 → 영혼 흡수·아군 소환 가능(소울 도플은 주인을 따라다님). 메두사 머리 원거리 석화 가능(석화 중엔 스토킹 시스템이 건드리지 않음). 공허 캡슐 흡수 가능(다음 밤 새 몸으로 스토킹 계속). 울트라 캡슐 어드벤처 불가(길들임 몹만).

### 은신 캡슐 / 변신
- 황혼의 검으로 처치 → 들고 있는 은신 캡슐에 자동 등록. 개수 무제한, 같은 종류 중복 등록 없음(이미 있으면 선택만 이동).
- `C`키 은신 탭: 파트너/소울창과 같은 카드형 목록(3D 미리보기+이름). 행별 [변신하기]/[삭제], 상단 ★ 인간으로 복귀 버튼(변신 해제). 변신 중 다른 행 변신하기 = 갈아타기.
- 변신 효과(참고 모드 기본값과 동일): 체력 상한 20·이동속도 상한 0.1(느린 몹은 그대로 느려짐), 공격·방어·넉백저항·점프력 복사. 1인칭에선 몸·손이 안 보이고 F5·남 시점에 변신 모습(공격 스윙·든 아이템·발광 복사).
- 특성: 비행몹 비행, 수생몹 호흡+수영 가속(돌고래의 우아함), 아홀로틀·돌고래 축축함 유예 후 건조 피해, 언데드 수중 호흡+재생·독 면역, 위더 전부·위더스켈레톤 시듦 면역, 거미 벽타기, 슬라임·마그마·유황큐브 둥실뜸, 골렘류 가라앉음, 말과 점프·발판 1칸, 고양이·개구리·골렘 추락 무시, 좀비계 햇빛 화상(투구 보호), 엔더맨·블레이즈·눈골렘·스트라이더 물 데미지.
- 공격: 근접은 몹 수치 + 접촉 효과(동굴거미 독·허스크 기아·위더·복어 독), 원거리는 투사체 교체(스켈레톤 화살·파치드 화살·드라우너드 삼지창·브리즈 윈드차지·블레이즈 작은 불덩이·가스트 불덩이·위더 해골 등). 크리퍼는 웅크리기 자폭.
- 같은 종/동족 몹은 선공 전까지 중립 (신규 타겟 차단 + 변신 전부터 물고 있던 타겟 해제 + 1초 스위퍼). 직접 때리면 10초간 중립 해제. 고양이·늑대·라마·좀비계 변신은 먹이몹이 도망감(크리퍼·스켈레톤·늑대·주민 등).
- 동기화: 서버 맵 권위 + 브로드캐스트 패킷(1초 재전파). 재접속해도 변신 유지. 접속 해제·서버 종료 때 캐시 전부 정리 + 입장 시 본인 상태 항상 재전송이라 다른 월드 유령 변신 없음.

### 규산(실리케이트) 장비 / 운석
- 성능 `다이아 < 규산 < 네더라이트`: 내구 1800/채굴 8.5/공격 3.5/인챈트 12, 방어 3/8/6/3, 강인 2.5, 밀저 0.05. 수리=`규산 주괴`.
- 조합: 파편 9→주괴, 검/곡/도끼/삽/괭이/투구/흉갑/레깅스/부츠 정석형. 블록은 다이아 곡괭이 이상, 파괴 시 파편 3개.
- 운석: 하루 경계 5%, 오버월드 랜덤 생존자 48~88m에 120틱 낙하 연출+분화구+규산 타원체. 채굴 시 10%로 먹보 도깨비 출현(운석당 1마리). 파편 들고 크리에+웅크리기 우클릭=강제 운석.

### 먹보 도깨비 / 공허 액체
- 먹보 도깨비: HP60/공8. `탐색→잡기→씹기→삼킴` 위상. 플레이어 10뎀, 일반몹 삼키면 되감기 기록 후 삭제. 엔드 자연 스폰(`END_STONE` 위, weight 8, 1~2마리).
- 사망 시 주변 최대 5칸 공허 액체 산포. 공허 액체=검은 물(무한수원, 물 취급). 양동이로 퍼서 공허 캡슐 조합.

### 화염몽 / 초월의 막대 / 열관 / 화염룡의 피
- 화염몽: HP40/공6, 불 원숭이. 사막에서만 소량 자연 스폰 (30초마다 25%, 64m 내 3마리 상한, 1~2마리). 집=근처 용암 웅덩이(32m 탐색). 이동속도 빠름(0.42, 마카크식 사지보행+너클워크+질주).
- 평소엔 온순: 주변 랜덤 불쏘기(입에서 3초간 길게, 6뎀+착화+빔 경로 착화), 나무 오르내리기(등반 포즈), 용암 안에서 휴식(화염 면역). 집 용암 10m 안에 플레이어 접근·직접 때리면 돌변: 추적+근접 6뎀+화염+막대 공격. 브레스는 입에서 12m 직선 빔으로만 발사.
- 소울 호환: 불길의 검 처치→소울 캡슐 저장→아군 소환 가능. 소울 화염몽은 방랑골 제거+주인/동료 오폭 차단(근접·브레스·지팡이), 적 킬은 영혼 흡수됨.
- 초월의 막대: 오른손 항상 소지. 겨눈 대상(16m) 이동속도 저하 3초, 쿨 10초. 플레이어도 주워서 우클릭 사용 가능.
- 드롭: 화염몽의 심장 1개 + 초월의 막대 1개 확정.
- 마그마 궁전: 사막 전용 구조물 (`UltraCapsuleAdventure:magma_palace`, 23x12x23 마그마 블록のみ, 2층+기둥+4개 방). 배치 지점마다 항상 생성, `/locate structure UltraCapsuleAdventure:magma_palace`로 탐색. 안에는 화염몽 1마리 보장(구조물 엔티티). 궁전이 집: 근처 마그마 밀집(400+)을 집으로 삼아 밖에서 활동해도 복귀. 밤(13000~23000)이 되면 집으로 귀가해 눕고 잔다(눕기 모션, 맞으면 기상). 소울 화염몽은 수면을 안 하고 주인을 따른다.
- 열관: 조합 `조약돌 8 + 심장 1`. 화로처럼 설치, 연료 없이 용광로 2배속(50틱)으로 제련. 모래/고기/광물 전부 가능. 우클릭=넣기, 빈손 우클릭=꺼내기, 웅크리기 우클릭=재료 회수.
- 화염룡의 피: 작업대 `심장 위 + 유리병 아래` → 3병. 마시면 3분간 빈손+`F` 꾹으로 입에서 화염 브레스(8m, 4뎀+착화).
